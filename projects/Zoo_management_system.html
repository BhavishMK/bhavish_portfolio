Zoo Management System

Image Generator

  • Tech Stack: Python, HTML, CSS, Bootstrap, GCP (Pub/Sub, Dataflow, Data Studio, GAE, BigQuery)
  • Github URL: Project Link

Created a web-based elastic application to provide users with a detailed analysis of sentiment for the top 10 trending movies and songs using Google Cloud Platform services.

Implemented a Pub/Sub routine to fetch 1000 tweets at a time from Twitter; utilized Dataflow for resource autoscaling and dynamic work rebalancing, reducing overall response time by 50%; and stored data in BigQuery for efficient display in Google DataStudio.

Tested the scalability of the web application by generating 10,000 user requests with Apache Beam.
